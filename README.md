# 대화 브리핑 — Windows 로컬 프로그램

Windows에서 기존 카카오톡 계정의 로컬 대화를 읽고 요약·일정·할 일·답장 초안을 관리하는 프로그램입니다. 현재 배포 채널은 시험용 프리릴리스입니다.

[설치 EXE 다운로드](https://github.com/CodeplantEDU/chatbrief/releases/download/v0.4.2-rc.1/ChatBrief-0.4.2-rc.1-windows-x64-setup.exe) · [전체 릴리스](https://github.com/CodeplantEDU/chatbrief/releases) · [사용 안내](TESTING.md)

설치 EXE에는 Python과 Node.js가 포함됩니다. WebView2가 없는 PC에서는 설치 중 인터넷으로 내려받습니다. AI 도구는 설정에서 선택 설치하고 본인 계정으로 로그인합니다.

## 실행

사용자 시험은 `release/ChatBrief-0.4.2-rc.1-windows-x64-setup.exe`를 실행합니다. [사용자 테스트 안내](TESTING.md)를 함께 확인합니다.
아래 스크립트는 개발용 소스 실행 방법이며, 설치형 사용자는 Python을 별도로 설치하지 않습니다.
다른 PC에서는 Python 3.12 이상과 Node.js LTS를 설치하고 `설치.cmd`를 먼저 실행합니다.
Python 의존성은 requirements.txt, 읽기 소스는 vendor/reader에 포함합니다.
AI CLI 실행 파일은 재배포하지 않고 공식 npm 패키지를 설치합니다.

1. 카카오톡을 기존 계정으로 실행합니다.
2. 대화 메뉴에서 방을 검색해 엽니다. 방을 여는 행동은 요약 체크 목록을 바꾸지 않습니다.
3. 지금 보고 있는 방만 요약하려면 대화 안의 요약 기능을 사용합니다. 오늘·전체·기간 범위와 방 이름을 확인합니다.
4. 여러 방을 함께 요약하려면 여러 방 요약 메뉴에서 대상 방을 체크합니다. 체크한 방만 실행하며 선택이 없으면 실행할 수 없습니다.
5. 설정에서 사용할 AI를 선택합니다. 연결 테스트는 실제 대화 대신 가상 메시지를 사용합니다.
6. 예약 관리는 왼쪽 메뉴에서 엽니다. 예약 대상은 일반 대화 요약 선택과 별도로 검색·선택합니다. 시간 기본값은 한국 시간 09:00입니다.
7. 예약을 켜고 예약 설정을 저장합니다. 대화 아래에서는 AI 답장 생성·초안 수정·복사·저장과 직접 전송을 사용할 수 있습니다.
8. 할 일 메뉴에서는 직접 추가·완료·보관을 지원합니다. 요약의 할 일로 추가 버튼 또는 자동 추가 설정을 사용할 수 있습니다.

선택을 해제해도 기존 요약은 홈에 남습니다. 선택·예약·AI·할 일 설정은 서로 다른 항목을 몰래 저장하지 않습니다. 다른 방으로 이동해도 작성 중인 답장은 앱 메모리에 유지되며, 앱을 닫기 전 영구 보관하려면 초안 저장을 누릅니다.

## 일일 실행

프로그램 서버가 실행 중일 때 내부 스케줄러가 선택한 시간에 AI 요약합니다.
Codex 앱의 자동화나 Windows 예약 작업은 별도로 등록하지 않았습니다.
설치 프로그램의 창을 닫으면 서버와 예약 확인도 종료됩니다. 소스 개발 모드에서는 서버 프로세스가 실행 중이어야 합니다.
PC 종료·절전·로그아웃 중에는 실행되지 않습니다. 서버를 다시 시작하면 놓친 실행을 한 번 확인합니다.
시작 프로그램 등록은 하지 않았습니다. 재부팅 뒤에는 바탕화면의 대화 브리핑 테스트를 다시 엽니다.
실패 시 무한 재시도하지 않습니다. 화면에서 실패를 확인하고 수동 실행할 수 있습니다.

전체 대화 요약은 이 PC의 로컬 저장 범위, 오늘 대화 요약은 한국 시간 00:00부터 현재까지를 대상으로 합니다. 예약 요약은 첫 확인 최근 24시간, 이후 마지막 성공한 예약 확인 이후 메시지를 읽습니다.
원문 확인은 AI 확인 위치를 전진시키지 않습니다. 1회 수집 한도는 방당 5,000개이며 도달 시 표시합니다.
처음 읽는 방 또는 키가 바뀐 방은 카카오톡에서 한 번 열어야 할 수 있습니다.
로컬 DB에 저장되지 않은 과거 기록과 닫힌 방의 새 메시지 즉시 동기화는 보장하지 않습니다.
첨부파일 본문은 읽지 않습니다. 원문 탭의 일정 후보는 날짜·시간 표현 검색이며 확정 일정이 아닙니다.
AI 요약은 추가·변경·취소 일정과 담당자·기한을 원문 근거와 함께 정리하도록 요청합니다. 할 일의 근거 메시지 ID를 원문 입력과 대조하고 중복 항목을 거릅니다. 자동 추가는 기본적으로 꺼져 있습니다. 전체·오늘 수동 요약은 예약의 확인 위치를 전진시키지 않습니다.
여러 방의 메시지는 선택한 AI에 한 번에 전달될 수 있습니다.

## AI 연결

기존 CLI 로그인을 사용합니다. 앱에 비밀번호·API 키를 입력하거나 보관하지 않습니다.
- Codex: `codex login`, 공식 `@openai/codex`
- Claude: `claude auth login`, 공식 `@anthropic-ai/claude-code`
- Gemini: `gemini`를 실행해 본인 인증, 공식 `@google/gemini-cli`

각 계정의 플랜·과금·이용 한도를 따릅니다. CLI 설치 확인과 실제 모델 응답 확인은 별개입니다.
AI로 요약하면 선택한 방의 메시지가 해당 제공자의 클라우드로 전송됩니다.
연결 실패 시 다른 AI로 자동 전송하지 않습니다. 사용자가 AI를 선택합니다.
도구 실행을 제한하고 대화를 명령이 아닌 데이터로 전달합니다.
Codex는 ephemeral, Claude는 no-session-persistence로 실행합니다.
Gemini CLI 자체는 로컬 세션을 남길 수 있습니다. 앱의 DPAPI 저장과 별개이며 해당 CLI의 기록 정책을 확인해야 합니다.
요약 결과는 모델 생성 내용이므로 원문과 대조해야 합니다.

## 데이터와 접근

서버는 127.0.0.1에만 바인딩합니다. 외부 PC에 공개하지 않습니다.
Host·Origin 검사 및 요청 토큰을 사용합니다. 외부 스크립트·폰트를 로드하지 않습니다.
선택 방·요약·수집 원문·커서는 `%LOCALAPPDATA%/ChatBrief/private/state.dpapi`에 현재 Windows 사용자 DPAPI로 암호화합니다.
브라우저에는 결과를 표시하며 같은 PC의 다른 프로세스에 대한 완전한 격리 수단은 아닙니다.
기존 읽기 모듈의 암호화 키 캐시는 원본을 보존하며 현재 사용자 데이터 폴더로 암호문만 이관할 수 있습니다. 배포본에는 포함하지 않습니다.
새 설치는 `%LOCALAPPDATA%/ChatBrief/reader-private`에 자기 계정의 키 캐시를 만듭니다. 실행 파일과 사용자 데이터는 분리됩니다.

## 소스와 권리 표시

새 UI·스케줄러·AI 연결 코드는 이 작업에서 작성했습니다.
읽기 엔진은 sanguneo/nichirin의 kanao 0.31.3 및 이전 kakaocli 작업에 기반하며 MIT 라이선스입니다.
수정 부분은 32비트 KakaoTalk 지원, 메모리 SQLite 읽기, DPAPI 키 캐시, 읽기 작업 제한 등입니다.
원본이 없어진 독점 소유 코드로 주장하지 않습니다. 원본 LICENSE와 SOURCE.json, THIRD_PARTY_NOTICES.md를 유지해야 합니다.
MIT는 고지 조건을 지키며 수정·사용·재배포를 허용합니다. 전체 프로그램의 다른 권리·서비스 약관까지 보장하는 뜻은 아닙니다.

## CLI 수동 점검

`app.py --collect`는 활성 설정의 새 메시지를 표준 출력으로 반환합니다.
`app.py --save-report`는 collection과 summaries를 갖는 JSON을 표준 입력으로 받아 암호화 저장합니다.
개인 원문을 평문 파일이나 저장소에 저장하지 마세요. private 폴더와 AI CLI 기록은 배포 대상에서 제외합니다.

## 대화와 첨부 보기

채팅방 이름을 누르면 보낸 사람·날짜·시간·내 메시지 방향을 구분한 대화가 표시됩니다.
100개 단위로 이전 대화를 더 불러올 수 있습니다.
이미지 보기와 파일 다운로드는 실제 대화에 기록된 카카오 CDN 주소에만 요청합니다.
CDN 원본 URL은 브라우저·로그·저장소에 노출하지 않고 서버 메모리의 임시 토큰으로 연결합니다.
열 수 없거나 만료된 첨부는 파일명·종류·크기·전송자·시간 등 존재하는 정보만 보여 줍니다.
파일 안의 텍스트를 분석하지 않습니다. 50MB 초과 파일은 직접 카카오톡에서 확인합니다.
이 PC에 다운로드되지 않았으며 CDN도 만료된 파일을 복원하는 기능은 아닙니다.

## 화면 설정

Pretendard v1.3.9를 로컬 파일로 포함하며 OFL 고지를 fonts/OFL.txt에 유지합니다.
라이트·다크 테마 선택은 해당 브라우저에 저장합니다. AI와 답장 말투 선택은 둥근 메뉴·키보드 탐색을 지원합니다.

## 전송과 Gemini의 현재 제한

답장 작성란에서 Enter 또는 직접 전송 버튼을 누르면 추가 확인창 없이 전송합니다. Shift+Enter는 줄바꿈입니다. 한글 입력 조합을 확정하는 Enter는 발송하지 않습니다. 사용자가 허용한 Win32 방식으로 열린 카카오톡 채팅방의 입력란을 조작합니다. 화면 인식·좌표 클릭·클립보드는 사용하지 않습니다.
카카오톡에서 대상 방을 먼저 열어 두어야 합니다. 같은 제목의 방이 여러 개이거나 기존 미완성 초안이 있으면 전송하지 않습니다. AI 초안은 자동 발송하지 않습니다.
입력란이 고정 안내 문구 ‘메시지 입력’을 반환하면 직접 전송 동작으로 그 문구를 대체합니다. 다른 기존 입력은 덮어쓰지 않습니다. 처리 중에는 카카오톡 입력창을 직접 조작하지 않습니다.
한 번 확인한 전송 요청은 한 번만 실행합니다. 결과가 불확실하면 자동으로 재시도하지 말고 실제 카카오톡을 확인합니다. 입력창이 비워졌다는 관찰은 상대방 수신·읽음 확인이 아닙니다.
Gemini 개인용 기존 CLI는 UNSUPPORTED_CLIENT 응답이 확인됐습니다. Codex·Claude를 우선 사용할 수 있습니다.
Gemini 대체 클라이언트 설치·본인 인증은 검증하지 않았습니다. 설정의 연결 테스트로 실제 연결 상태를 확인합니다.
공식 안내: https://antigravity.google/docs/cli/gcli-migration/

## 검증 범위

가상 데이터로 예약 시간·오늘/전체 범위·DPAPI 저장·중복 할 일 거부·응답 형식·첨부 주소 제한을 검사합니다.
카카오톡 실제 목록·원문·첨부 메타데이터 조회를 확인했습니다.
재부팅과 실제 예약 시간 도달·모든 첨부파일 열기·직접 답장 전송은 시험하지 않았습니다.

## 홈·기간 요약·대화와 요약 나란히 보기

홈은 전체 브리핑, 채팅방별 최신 요약과 실행 이력을 표시합니다. 예약 결과는 예약 배지로 구분하며 시간순으로 누적합니다.
기존 저장 결과도 홈에서 볼 수 있도록 이관합니다. 홈의 대화 보기·요약 보기는 해당 채팅방으로 연결합니다.
일반 요약 화면에서 시작일·종료일을 정해 해당 날짜를 모두 포함하여 요약할 수 있습니다. 한국 시간 기준입니다.
채팅방 목록과 예약 대상 목록에는 각각 검색 결과 전체 선택·선택 해제가 있습니다. 서로의 선택을 바꾸지 않습니다.
대화 화면의 요약 패널 열기를 누르면 오른쪽에 요약이 추가됩니다. 세로 경계를 드래그하거나 키보드 방향키로 너비를 바꿉니다.
너비는 브라우저에 저장합니다. 좁은 화면에서는 패널을 아래로 배치합니다.
전체 브리핑은 채팅방별 최신 요약을 모은 화면이며, 원문에 없는 종합 결론을 별도로 만들어 넣지 않습니다.

## 설치형 테스트 빌드

설치형은 Windows 프로그램 창과 전용 백그라운드 읽기 worker를 포함합니다. 원본 읽기 모듈을 별도 설치한 Codex 폴더에 의존하지 않습니다.
`requirements-build.lock`을 사용하는 전용 Python 3.12 빌드 환경에서 `build_release.py`로 생성합니다.
빌드 도구는 검증한 NSIS 3.13 ZIP을 `.build-tools/nsis-3.13`에 두며 공식 SHA-256은 `ba63dffc4410ee89193e1cb5a41989991bd77c61068da17e3156d136b7b0b3d8`입니다.
빌드 결과는 `release`에 생성합니다. 공개 릴리스에는 설치 EXE·포터블 ZIP·소스 ZIP과 SHA-256 목록을 첨부합니다. 설치 폴더는 현재 사용자 `Programs/ChatBrief-Test`이며 제거 후 사용자 데이터는 유지합니다.
소스 실행에서만 기존 작업 폴더 설정을 찾을 수 있으므로, 이번 로컬 전환은 설치 전에 소스의 `ensure_runtime()`으로 현재 사용자 데이터 폴더에 원본을 보존해 이관합니다. 일반 설치본이 임의의 과거 작업 폴더를 검색하지는 않습니다.

## 대화 자동 갱신

열어 둔 대화는 대화 화면이 활성화되어 있을 때 주기적으로 새 메시지를 확인합니다. 직접 전송 후에도 대화를 다시 읽습니다. 갱신 중 기존 메시지·작성 중인 답장·읽던 위치를 유지하며, 새 메시지가 없으면 화면을 다시 그리지 않습니다. 이 PC의 카카오톡 로컬 DB에 저장된 내용만 반영하므로 서버에서 이 PC로 아직 동기화되지 않은 메시지는 표시되지 않을 수 있습니다.

신규 앱 소스에 별도의 오픈소스 라이선스를 부여하지 않았습니다. 포함된 제3자 소스와 글꼴에는 각각의 MIT·OFL 등 고지가 적용됩니다. 코드 서명이 없는 Windows 시험용 빌드입니다.
