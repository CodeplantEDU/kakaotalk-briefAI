# KakaoTalk BriefAI

카카오톡 대화를 읽고 AI 요약·일정·할 일·답장을 관리하는 Windows 프로그램입니다.

**[Windows 설치 EXE 다운로드](https://github.com/CodeplantEDU/kakaotalk-briefAI/releases/download/v0.4.4-rc.1/KakaoTalk-BriefAI-0.4.4-rc.1-windows-x64-setup.exe)** · [전체 다운로드](https://github.com/CodeplantEDU/kakaotalk-briefAI/releases)

> 카카오가 제작·승인·지원하지 않는 비공식 프로그램입니다. 이용 방식에 따라 계정이 제한될 수 있습니다. 아래의 이용·면책 고지를 읽고 사용해 주세요.

## 시작하기

1. **설치:** 위 EXE를 설치한 뒤 바탕화면의 **KakaoTalk BriefAI**를 엽니다. Windows 64비트용이며 Python과 Node.js가 포함되어 있습니다. 별도 실행·설치 스크립트는 필요하지 않습니다. WebView2가 없는 PC에서는 설치 중 인터넷으로 내려받습니다.
2. **카카오톡:** 이 PC에서 평소 사용하는 계정으로 카카오톡을 실행합니다. 앱을 위해 별도로 카카오톡에 로그인하거나 기존 계정을 로그아웃할 필요가 없습니다.
3. **AI 연결:** 왼쪽 **설정**에서 사용할 Codex·Claude·Gemini를 선택합니다. 필요한 도구의 **설치하기**를 누른 다음, 로그인 안내에 표시된 명령을 복사해 PowerShell에서 실행하고 본인 계정으로 인증합니다. 비밀번호·인증 코드를 프로그램이나 공개 이슈에 적지 마세요.
4. **연결 확인:** **연결 테스트**를 눌러 확인합니다. 이 버튼은 실제 대화 대신 가상 메시지를 사용합니다. AI 도구의 계정별 이용 한도·요금 정책이 적용됩니다.

처음에는 실제 기능 화면을 따라 사용하는 안내가 열립니다. 계정이나 대화가 준비되지 않은 단계는 건너뛸 수 있고, **설정 → 튜토리얼 다시 보기**에서 다시 시작할 수 있습니다.

## 사용 방법

### 대화 보기

왼쪽 **대화**에서 채팅방 목록을 새로고침하고 방 이름을 검색해 엽니다. 말풍선으로 대화를 보고 이미지·첨부파일을 확인할 수 있습니다. 열 수 없거나 만료된 첨부는 파일명·종류·전송자·시간 등 확인 가능한 정보만 표시합니다. **이전 대화 불러오기**로 앞선 메시지를 더 확인합니다.

처음 읽거나 키가 변경된 방은 카카오톡에서 한 번 열어야 할 수 있습니다. 이 PC에 저장된 범위만 읽으며, PC로 아직 동기화되지 않은 메시지나 모든 과거 기록을 보장하지 않습니다. 대화 화면이 활성화되어 있으면 약 5초마다 새 메시지를 확인하고, 전송 후에도 갱신합니다.

### 대화 요약하기

| 원하는 작업 | 사용 방법 |
|---|---|
| 지금 보고 있는 방 요약 | 대화 화면에서 **전체·오늘·기간** 중 범위를 고르고 이 방 요약 실행 |
| 날짜를 정해서 요약 | **기간**을 고른 뒤 시작일·종료일 입력 |
| 여러 방 한 번에 요약 | **여러 방 요약**에서 대상 방을 체크한 뒤 요약 실행 |
| 검색 결과 모두 선택 | 해당 목록의 **검색 결과 전체 선택** 사용 |
| 원문과 요약 함께 보기 | 대화의 **요약 패널 열기** 사용, 경계를 드래그해 너비 조절 |

방을 열어 보는 것과 여러 방 요약의 체크 선택은 별개입니다. 체크를 해제해도 이미 만든 요약은 사라지지 않습니다. AI 요약·일정·할 일은 원문과 대조해 확인합니다.

### 답장 작성·전송

대화 아래에서 **이 방의 내 말투**를 선택해 AI 답장을 생성할 수 있습니다. 같은 방에서 본인이 보낸 메시지를 참고하며, 샘플이 부족하면 안내합니다. 생성된 초안을 읽고 직접 수정하거나 저장합니다.

- **Enter / 직접 전송:** 추가 확인창 없이 발송 요청
- **Shift+Enter:** 줄바꿈
- **본문:** 텍스트 최대 2,000자
- **전송 조건:** 카카오톡에서 같은 방이 별도 창으로 열려 있어야 함
- **기존 입력 보호:** 카카오톡 입력란에 다른 초안이 있으면 전송 차단
- **불확실한 결과:** 자동으로 다시 보내지 않음. 실제 카카오톡에서 결과를 먼저 확인

전송 요청 완료는 상대방의 수신·읽음 확인이 아닙니다. 앱을 닫기 전에 작성 중인 답장을 보관하려면 **초안 저장**을 누릅니다.

### 할 일 정리

**할 일**에서 내용을 직접 추가하거나 요약 결과의 **할 일로 추가**를 사용합니다. 완료·보관 상태를 관리할 수 있습니다. 요약의 할 일을 자동으로 추가하려면 설정에서 **자동 추가**를 선택합니다. 자동 추가는 기본적으로 꺼져 있습니다.

### 매일 예약하기

1. **예약 관리**에서 채팅방 목록을 새로고침하고 예약할 방을 검색·선택합니다.
2. 확인 시간을 지정합니다. 기본값은 **한국 시간 오전 9시**입니다.
3. **일일 확인 켜기**를 선택하고 **설정 저장**을 누릅니다.
4. **홈**에서 전체 브리핑과 채팅방별 요약, 누적된 예약 결과를 확인합니다.

예약 대상은 여러 방 요약의 체크 선택과 독립적입니다. 프로그램과 카카오톡이 실행 중일 때 확인하며, 프로그램 창을 닫거나 PC가 종료·절전 중이면 실행되지 않습니다. 재부팅 뒤에는 프로그램을 다시 엽니다. 일정 후보가 곧 확정된 일정이나 외부 캘린더 등록을 의미하지는 않습니다.

### 화면 설정

왼쪽 아래에서 **라이트·다크 모드**를 바꿉니다. 대화 오른쪽의 요약 패널은 경계를 드래그하거나 방향키로 너비를 조절할 수 있습니다. 사용 안내는 **설정 → 튜토리얼 다시 보기**에서 다시 엽니다.

## 데이터와 개인정보

- 설정·요약·원문·키 캐시는 `%LOCALAPPDATA%\ChatBrief`에 현재 Windows 사용자 계정의 DPAPI로 암호화해 보관합니다.
- 업데이트하거나 프로그램을 제거해도 사용자 데이터를 지우지 않습니다. 다른 Windows 계정이나 PC에서는 기존 암호화 데이터를 열지 못할 수 있습니다.
- **AI 요약·답장 생성 시 선택한 대화가 사용자가 고른 AI 서비스로 전달됩니다.** 해당 서비스의 이용 한도·요금·기록 정책이 적용됩니다. 다른 AI로 자동 전환하지 않습니다.
- 첨부파일을 열 때 카카오 CDN에 연결할 수 있습니다. 첨부파일 본문은 AI 요약에 포함하지 않습니다.
- 대화·인증 정보·키 캐시·개인 설정은 배포 파일에 포함하지 않습니다. 공개 이슈에도 첨부하지 마세요.

## 비공식 프로그램 및 이용·면책 고지

카카오와 제휴·보증 관계가 없습니다. 접근 권한·개인정보·발송 내용·약관과 법령 준수는 사용자가 확인해야 합니다. 법률이 허용하는 범위에서 보증과 개발자·배포자·기여자의 책임을 제한하며, 법률상 배제할 수 없는 책임은 제외합니다.

### 카카오 비공식 프로그램

KakaoTalk BriefAI는 독립적으로 제작·배포하는 비공식 프로그램입니다. 주식회사 카카오가 제작하거나 검토·승인·지원하지 않습니다. 카카오와 제휴 또는 보증 관계가 없습니다. 카카오톡·KakaoTalk과 관련 상표는 카카오에 귀속되며, 여기서는 연동 대상을 설명하기 위해 사용합니다.

### 작동 방식과 한계

이 프로그램은 사용자의 Windows PC에 저장된 카카오톡 대화를 읽습니다. 전송 기능은 로그인된 카카오톡의 열린 대화창을 Win32 방식으로 조작합니다. Enter 또는 직접 전송 버튼은 추가 확인창 없이 발송을 요청하며 Shift+Enter는 줄바꿈입니다. 전송 요청 완료 표시는 상대방의 수신·읽음을 보장하지 않습니다.

요약·답장 생성 시 선택한 대화가 사용자가 선택한 AI 서비스에 전달됩니다. 첨부파일 열기는 카카오 CDN에 연결할 수 있습니다. 결과가 완전하거나 정확하다는 보장은 없으며, 일정·할 일·답장은 원문과 대조해야 합니다. 카카오톡 업데이트나 실행 환경 변화로 기능이 중단될 수 있습니다.

### 사용자 책임과 금지 용도

대화에 접근할 권한, 개인정보·비밀의 처리, 데이터 보관·공유, 발송 대상과 본문, 카카오 및 AI 서비스 약관과 관계 법령 준수는 사용자가 확인하고 책임져야 합니다. 비공식 연동 방식의 이용으로 계정 또는 기능이 제한될 수 있으며 이를 방지하거나 해제한다고 보장하지 않습니다.

무단 접근·도용·사칭, 스팸·동의 없는 광고, 감시·괴롭힘, 동의 없는 개인정보 수집과 무인 대량 발송에 사용하지 마세요. AI나 에이전트가 수행한 작업도 사용자 계정에서 실행됩니다.

### 보증 부인 및 책임 제한

소프트웨어와 문서는 있는 그대로 제공됩니다. 법률이 허용하는 범위에서 특정 목적 적합성, 지속적인 동작, 데이터의 완전성, 메시지 전달, 계정 안전성 등을 보증하지 않습니다.

법률이 허용하는 범위에서 개발자·배포자·기여자는 사용 또는 사용 불능에 따른 오발송·중복·미전송, 데이터 손실·유출, 계정 제한, AI 결과 오류, 영업 손실과 제3자 분쟁 등 직접·간접 손해에 책임을 지지 않습니다. 고의·중대한 과실이나 소비자 권리 등 법률상 배제할 수 없는 책임에는 적용되지 않습니다. 이 고지가 모든 책임을 배제하거나 적법한 사용을 보장하는 것은 아닙니다.
