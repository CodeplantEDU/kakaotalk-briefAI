# KakaoTalk BriefAI 사용 안내

## 설치와 AI 연결

릴리스의 설치 EXE를 설치한 뒤 바탕화면의 KakaoTalk BriefAI를 엽니다. Python과 Node.js는 포함되어 있습니다. 사용할 AI는 설정에서 선택 설치하고 본인 계정으로 로그인한 다음 연결 상태를 확인합니다. 계정의 이용 한도·요금 정책이 적용됩니다.

## 대화와 요약

카카오톡을 기존 계정으로 실행하고 앱의 대화 메뉴에서 방 목록을 새로고침해 원하는 방을 검색합니다. 방을 열면 대화·첨부파일이 표시됩니다. 전체·오늘·기간 중 범위를 선택해 이 방을 요약할 수 있습니다. 여러 방 요약은 별도로 체크한 방만 대상으로 합니다.

이전에 확보한 키가 없거나 변경된 방은 카카오톡에서 한 번 열어야 할 수 있습니다. 이 PC의 로컬 저장 범위만 조회하며, 열 수 없는 첨부는 파일 정보만 표시합니다.

## 답장과 할 일

대화 아래에서 AI 답장을 생성하고 내용을 확인·수정합니다. Enter 또는 직접 전송 버튼은 추가 확인창 없이 보내며 Shift+Enter는 줄바꿈입니다. 전송하려면 해당 방이 카카오톡의 별도 창으로 열려 있어야 합니다. 기존 카카오톡 입력란에 다른 초안이 있으면 보내지 않습니다. 결과가 불확실하면 자동으로 다시 보내지 않습니다.

할 일은 직접 입력하거나 요약 결과에서 추가할 수 있습니다. 요약의 할 일 자동 추가는 설정에서 선택합니다. AI 결과는 원문과 대조합니다.

## 예약과 화면 설정

예약 관리에서 대상 방과 시간을 별도로 선택하고 저장합니다. 예약을 켜면 실행 중인 프로그램이 지정한 시간에 확인합니다. PC 종료·절전 중에는 실행되지 않으며 프로그램 창을 닫으면 예약 확인도 종료됩니다.

홈에는 요약과 예약 브리핑이 누적됩니다. 대화의 오른쪽 요약 패널은 너비를 조절할 수 있습니다. 라이트·다크 모드와 튜토리얼 다시보기는 화면 설정에서 사용할 수 있습니다.

## 데이터와 이용 고지

설정·요약·원문·키 캐시는 현재 Windows 사용자 계정으로 암호화해 보관합니다. 업데이트하거나 프로그램을 제거해도 사용자 데이터를 지우지 않습니다. 다른 PC나 계정으로 옮기면 기존 암호화 데이터를 열지 못할 수 있습니다. 요약·답장 생성 시 선택한 대화가 사용자가 고른 AI 서비스에 전달됩니다.

카카오와 무관한 비공식 프로그램입니다. 계정 제한 가능성, 사용자 책임, 보증 및 책임 제한은 앱 설정 또는 [전체 이용·면책 고지](https://github.com/CodeplantEDU/kakaotalk-briefAI/blob/main/DISCLAIMER.md)에서 확인합니다.

Windows 코드 서명은 적용하지 않았습니다. 실제 카카오톡 발송, 한글 조합 중 Enter, 스크롤 보존 실측, 새 PC 설치 등 일부 동작은 검증 완료 항목이 아닙니다.
