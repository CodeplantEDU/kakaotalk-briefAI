# KakaoTalk BriefAI

Windows에서 카카오톡 대화를 보고, AI 요약·일정·할 일·답장을 관리하는 프로그램입니다.

**[Windows 설치 EXE 다운로드](https://github.com/CodeplantEDU/kakaotalk-briefAI/releases/download/v0.4.4-rc.1/KakaoTalk-BriefAI-0.4.4-rc.1-windows-x64-setup.exe)**

EXE 하나로 설치합니다. Python과 Node.js가 포함되며 별도의 실행 스크립트는 필요하지 않습니다. WebView2가 없는 PC에서는 설치 중 인터넷 연결이 필요합니다.

## 주요 기능

- 채팅방 검색, 대화·이미지·첨부파일 확인
- 전체·오늘·기간별 요약과 채팅방별 브리핑
- 매일 지정 시간에 선택한 방의 대화·일정 정리
- 같은 방의 내 말투를 참고한 AI 답장과 할 일 관리
- Enter·직접 전송으로 보내기, Shift+Enter 줄바꿈
- 전송 후 및 대화 화면의 주기적인 자동 갱신

설정에서 사용할 AI를 선택하고 본인 계정으로 연결합니다. [사용 안내](https://github.com/CodeplantEDU/kakaotalk-briefAI/blob/main/docs/USAGE.md) · [전체 다운로드](https://github.com/CodeplantEDU/kakaotalk-briefAI/releases)

## 비공식 프로그램 및 이용 책임

카카오가 제작·승인·지원하는 공식 프로그램이 아닙니다. 이용 방식에 따라 계정이 제한될 수 있습니다. 대화 접근 권한, 개인정보 처리, 발송 대상·본문과 약관·법령 준수는 사용자가 확인해야 합니다.

법률이 허용하는 범위에서 보증 없이 제공되며 개발자·배포자·기여자의 책임을 제한합니다. 법률상 배제할 수 없는 책임은 제외합니다. [전체 이용·면책 고지](https://github.com/CodeplantEDU/kakaotalk-briefAI/blob/main/DISCLAIMER.md)

읽기 엔진은 nichirin/kanao·kakaocli의 MIT 소스를 기반으로 하며, Pretendard는 OFL 고지를 포함합니다. [제3자 고지](https://github.com/CodeplantEDU/kakaotalk-briefAI/blob/main/source/THIRD_PARTY_NOTICES.md)
